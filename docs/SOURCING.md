# 소재 큐 사용법 (Phase 9)

> 콘티를 만들려면 **"무슨 상품으로 만들지"** 가 먼저 정해져야 합니다.
> 그 소재가 쌓이는 곳이 `content/queue.json` 입니다.

## 왜 파일 하나를 정해두는가

원안의 소재 발굴 담당은 **그록(X 실시간 트렌드)** 인데 지금은 API가 막혀 있습니다.
그렇다고 손 놓고 기다릴 이유는 없습니다. **채우는 주체만 다르고 결과물은 같기 때문입니다.**

```
        content/queue.json   ← 계약(인터페이스)
              ↑         ↑
   ① 폰 그록 앱 결과      ② scripts/grok_trends.py
      붙여넣기 (지금)         (정책 열린 뒤 — Phase 8)
              ↓
      make_toon.py "키워드"  →  콘티
```

지금 사람이 채우다가 나중에 스크립트로 갈아끼울 때 **뒷단 코드를 다시 안 짜도 됩니다.**
계획서 원칙 1(손으로 1번 성공 → 스크립트화 → 자동화) 그대로입니다.

## 지금 하는 법 (수동)

### 1단계 — 폰에서 그록에게 물어보기

그록 앱에 아래를 그대로 붙여넣으세요.

```
지금 X에서 최근 일주일 사이 화제된 생활 꿀템·가성비템 5개 뽑아줘.

각각 이 형식으로:
- 상품명 (일반명사로. 브랜드명 말고)
- 왜 화제인지 한 줄
- 쿠팡에서 살 수 있는 물건인지 (O/X)
- 화제도 (상/중/하)

과장 없이, 실제로 언급량이 있었던 것만.
```

> **왜 브랜드명이 아니라 일반명사인가**: 콘티는 "이런 불편 → 이 물건이 해결" 구조라
> 특정 브랜드가 아니라 **물건 종류**가 필요합니다. 브랜드는 나중에 링크 걸 때 정합니다.

### 2단계 — 결과를 큐에 넣기

나온 결과를 저(Claude Code)한테 그대로 붙여넣어 주시면 `queue.json` 에 정리해 넣습니다.
직접 넣고 싶으시면 `scripts/queue.py` 를 쓰세요:

```bash
# 소재 하나 추가
python scripts/queue.py add "겨울 온열매트" --why "한파로 난방비 얘기 많음" --heat 상 --source grok

# 큐 보기
python scripts/queue.py list

# 다음에 만들 것 하나 꺼내기 (상태만 바꿈, 지우지 않음)
python scripts/queue.py next
```

### 3단계 — 콘티 뽑기

```bash
python scripts/make_toon.py "겨울 온열매트"
```

## queue.json 스키마

```json
{
  "schema_version": 1,
  "updated": "2026-09-03",
  "items": [
    {
      "keyword": "겨울 온열매트",
      "why": "한파로 난방비 얘기 많음",
      "heat": "상",
      "source": "grok",
      "coupang": true,
      "status": "todo",
      "added": "2026-09-03",
      "note": ""
    }
  ]
}
```

| 필드 | 뜻 | 값 |
|---|---|---|
| `keyword` | 상품 키워드 (일반명사) | 필수 |
| `why` | 왜 지금 이게 화제인지 | 후킹 각도의 재료가 됨 |
| `heat` | 화제도 | `상` / `중` / `하` |
| `source` | 어디서 나왔나 | `grok` / `coupang` / `naver` / `manual` |
| `coupang` | 쿠팡에서 살 수 있나 | `true` / `false` — false 면 수익화 불가 |
| `status` | 진행 상태 | `todo` → `doing` → `done` / `drop` |
| `added` | 큐에 넣은 날 | 오래된 트렌드는 식는다 |
| `note` | 메모 | 자유 |

### 상태 흐름

```
todo  ──▶  doing  ──▶  done
  │                     (콘티+작화+발행까지 끝)
  └──▶  drop
        (쿠팡에 없거나, 식었거나, 소재가 안 나옴)
```

---

## 운영 규칙

- **`coupang: false` 는 콘티를 만들지 않습니다.** 링크를 못 거니 수익이 0입니다.
- **`added` 로부터 2주 지난 `todo` 는 재검토합니다.** 트렌드는 식습니다.
- **한 번에 5개 이상 쌓지 않습니다.** 계획서 성공 기준이 주 3~5건이고,
  큐가 길어지면 오래된 소재가 썩습니다.
- **큐가 비면 그록에게 다시 물어봅니다.** 주 1회면 충분합니다.

## 나중에 (Phase 8, 정책 열린 뒤)

`scripts/grok_trends.py` 가 이 파일을 자동으로 채웁니다.
그록 API의 **Live Search** 옵션을 켜야 X 실시간 데이터가 나옵니다 —
그냥 부르면 일반 LLM처럼 답합니다. 검색 건당 과금이므로 **주 1회 배치**로 돕니다.
쿠팡파트너스 API가 승인되면 `source: "coupang"` 으로 **실제 판매 순위**가 함께 들어옵니다.
