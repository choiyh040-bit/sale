지금 세션에서 실제로 한 작업을 작업일지로 기록해 주세요.

절차:

1. `docs/templates/worklog-template.md` 양식을 읽습니다.
2. `logs/worklog/` 를 확인해 오늘 날짜의 다음 순번을 정합니다. 파일명은 `YYYY-MM-DD-NN.md` 입니다.
3. `git log -3 --stat` 과 이번 대화에서 실제로 한 작업을 근거로 아래 네 칸을 채웁니다.
   - **무엇을 했나** — 코드 나열이 아니라 "무슨 문제를 해결했는지"
   - **왜 이렇게 했나** — 다른 선택지를 왜 버렸는지
   - **막힌 점 / 배운 점** — 에러 메시지 원문, 삽질 내용, 해결 방법 (여기가 제일 중요)
   - **다음 할 일**
4. 표 머리(시각·Phase·커밋·분기점 유형)와 변경 파일 목록도 실제 값으로 채웁니다.
5. 마지막 줄의 `<!-- meta: hash=... -->` 에 관련 커밋 해시를 넣습니다.
6. 다 쓰면 `docs/TODAY.md` 의 C(Check)와 A(Act) 칸도 함께 갱신합니다.

**중요**: 추측해서 쓰지 마세요. 실제로 일어난 일만 씁니다.
안 된 것, 막힌 것을 빼놓지 마세요 — 그게 일지의 목적입니다.
