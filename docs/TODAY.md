  - `git push origin --delete` → `HTTP 403`. 세션 권한 밖. 사용자가 웹 UI로 직접 삭제.

    `git -c user.name=... commit` 을 못 잡은 것.

    `graph.facebook.com` 전부 `HTTP 000`. 도달하는 건 `googleapis.com` 하나.
    → 트렌드 수집뿐 아니라 **인스타 업로드 연동도 여기서는 못 돌린다.**
