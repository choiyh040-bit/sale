## 한 장 요약 (세션마다 자동 로드되는 부분)

- **무엇**: 쿠팡파트너스 / 토스 쉐어링크 제휴 링크로 수익을 내는 **인스타툰 계정**의 제작 파이프라인.

  **작화는 사람** → 말풍선 합성 → **텔레그램 승인** → 인스타 발행.
- **원안에서 바뀐 것은 딱 하나**: 작화를 이미지 생성 API 대신 **사람이 직접** 그린다 (2026-08-31).

- **원칙 3가지**
  1. **손으로 1번 성공 → 스크립트화 → 자동화.** 순서를 뒤집지 않는다.
  2. **완전자동 금지, 반자동이 목표.** 발행 직전 검수 단계는 끝까지 남긴다.
  3. **한 Phase = 혼자서도 돌아가는 결과물 1개.** 반쪽짜리로 다음으로 넘어가지 않는다.
- **작업 환경**: **핸드폰 + Claude Code 웹(원격 컨테이너).** 로컬 PC가 아니다.
  코드는 전부 컨테이너에서 실행하고, 결과는 git으로만 남는다. 컨테이너는 세션이 끝나면 사라진다.
- **★ 최대 병목: 네트워크 정책.** 그록·GPT·쿠팡·인스타·텔레그램이 전부 **차단**되어 있다.

  → 4-0절 참조. 이게 지금 프로젝트에서 가장 값어치 큰 단일 조치다.
- **현재 위치**: `docs/TODAY.md` 상단의 "현재 Phase" 를 기준으로 삼는다.
- **절대 규칙**: API 키는 환경변수/`.env` 에만. 절대 커밋 금지. 게시물에는 제휴 고지 문구 필수.

### 3-1. LLM 분업 (원안 구조)

원안의 핵심은 **한 모델이 다 하지 않는다**는 것입니다. 단계별로 잘하는 놈이 다릅니다.

| 단계 | 원안 담당 | 현재 상태 | 비고 |
|---|---|---|---|
| 트렌드 소싱 | **그록** | 🔴 API 차단 → **폰 앱으로 수동** | X 실시간 데이터가 강점 |
| 소재 앵글 | **GPT** | 🔴 API 차단 → 당분간 Claude/Gemini가 겸함 | 전환 포인트 도출 |
| **콘티·대본** | **Claude** | ⚠️ **현재 Gemini로 임시 운영** | 한국어 구어체·스토리 구성 최강 |
| 단순 분류·태깅 | Haiku 급 | 미사용 | 나중에 비용 절감용 |

> ⚠️ **알려진 불일치**: 원안과 이 계획서는 콘티 담당을 **Claude**로 잡고 있는데,
> 실제 코드(`scripts/make_toon.py`)는 **Gemini**로 돌아갑니다.
> Phase 0에서 확보된 키가 Gemini뿐이라 급히 갈아탄 것이고, **의도된 최종 상태가 아닙니다.**

> 앤트로픽 키만 넣으면 원안대로 되돌릴 수 있습니다. → Phase 11

## 4. 반드시 알아야 할 제약 (여기서 사업이 망가집니다)

### 4-0. ★네트워크 정책 — 현재 최대 병목★

이 컨테이너의 아웃바운드는 **정책 프록시**를 거칩니다. 허용되지 않은 호스트는
`403 to CONNECT (policy denial)` 로 막힙니다. **실측 결과 (2026-09-03):**

| 호스트 | 용도 | 결과 |
|---|---|---|
| `api.anthropic.com` | Claude API (콘티) | 🟢 **도달** |
| `generativelanguage.googleapis.com` | Gemini API | 🟢 **도달** |
| `api.x.ai` | **그록** — 트렌드 소싱 | 🔴 차단 |
| `api.openai.com` | GPT — 소재 앵글 | 🔴 차단 |
| `api.telegram.org` | 승인 봇 | 🔴 차단 |
| `slack.com` | 승인 봇(대안) | 🔴 차단 |
| `api-gateway.coupang.com` | 파트너스 — 링크·순위 | 🔴 차단 |
| `graph.facebook.com` | 인스타 발행 | 🔴 차단 |

**이건 버그가 아니라 환경 생성 시 고른 설정입니다.** 즉 **바꿀 수 있습니다.**

> claude.ai/code → **환경(Environment) 설정 → 네트워크 정책**에서 허용 도메인을 넓힙니다.
> 문서: https://code.claude.com/docs/en/claude-code-on-the-web

**정책을 열면 Phase 5·6·8·9·10 이 한 번에 풀립니다.** 반대로 열지 않으면
이 프로젝트는 "콘티 만들고 그림 얹어서 사람이 직접 인스타에 올리는 것"까지가 한계입니다.

- 진단: `curl -sS "$HTTPS_PROXY/__agentproxy/status"` → `recentRelayFailures` 에 차단 사유가 남습니다.
- **우회 시도 금지.** TLS 검증을 끄거나 프록시를 벗어나려 하지 않습니다.

### 4-1. 제휴 고지는 법적 의무
쿠팡파트너스 링크가 들어간 게시물에는 **수수료를 받는다는 고지 문구**가 반드시 들어가야 합니다.
표시광고법 / 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 대상입니다.

- 문구는 **본문 캡션 첫 부분** 또는 이미지 안에, 잘 보이게.
- "더보기" 안에 숨기거나, 해시태그 무더기 뒤에 끼워넣으면 위반 소지.
- 표준 문구: `이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따라 일정액의 수수료를 제공받습니다.`
- 토스 쉐어링크도 자체 약관의 고지 요건을 별도 확인할 것.

### 4-2. 인스타그램 링크의 현실 ★중요★
> 원안(제미나이 답변)에는 "첫 댓글에 제휴 링크 삽입" 이라고 되어 있는데, **이건 실무에서 잘 안 됩니다.**

- 인스타그램은 **캡션과 댓글의 URL을 클릭 가능하게 만들지 않습니다.** 그냥 텍스트로 보입니다.
- 유일하게 클릭되는 링크는 **프로필의 링크(링크인바이오)** 와 스토리 링크 스티커입니다.
- 따라서 실제 동선은:
  `게시물 → "프로필 링크 확인" 유도 → 링크인바이오 페이지 → 개별 제휴 링크`
- **Phase 5 이전에 링크인바이오 페이지부터 만들어야 합니다.** (Linktree 또는 자체 정적 페이지)
- 이 구조가 없으면 게시물을 아무리 많이 올려도 클릭이 0입니다.

### 4-3. Instagram Graph API 요건
- 계정이 **프로페셔널 계정(비즈니스 또는 크리에이터)** 이어야 함. **전환은 무료입니다.**
  (유료인 Meta Verified 는 별개이고 이 프로젝트에 불필요)
- **Facebook 페이지와 연결**되어 있어야 함. 순서: ①프로페셔널 전환 → ②페이지 생성 → ③연결
- Meta 개발자 앱 생성 + `instagram_content_publish` 권한 승인 필요 (앱 심사 있음).
- **하루 발행 한도 25건.** 캐러셀은 최대 10장.
- 액세스 토큰은 만료됨 → 장기 토큰 갱신 로직 필요 (Phase 5에서 처리).
- Graph API 는 로컬 jpg 를 안 받고 **공개 URL** 을 요구함 → 이미지 호스팅 경로 필요.

### 4-4. 작업 환경 제약 (핸드폰 + 원격 컨테이너)
- **로컬 PC가 없다.** 가상환경, `pip install`, 스크립트 실행 전부 원격 컨테이너에서 한다.
- **컨테이너는 세션이 끝나면 사라진다.** 남기고 싶은 건 반드시 **커밋 + 푸시**.
  설치한 패키지도 매 세션 다시 깔린다(느리지만 자동).
- **API 키는 `.env` 에 두면 세션마다 날아간다.** 환경 설정의 **환경변수**로 넣어야 유지된다.
  절대 채팅창에 붙여넣지 않는다 — 대화 기록에 영구히 남는다.
- **차단된 사이트**: 4-0절 표 참조. 추가로 `aistudio.google.com`(키 발급 페이지)도 차단
  → 키 발급은 **폰 브라우저로**.
- **생성된 이미지를 폰에서 보는 법**: GitHub에서 보거나, 채팅으로 파일을 받는다.
- **Phase 6(n8n Docker)은 폰에서 불가능하다.** 그 시점에 PC를 쓰거나 클라우드 호스팅으로 간다.

|---|---|---|
| **그록 (X 실시간)** | 🔴 `api.x.ai` 차단 / 🟢 **폰 앱은 지금도 됨** | ★★★ **원안 담당.** 바이럴 밈·핫딜 캐칭 |
| **쿠팡파트너스** | 🔴 차단 + 파트너 승인 필요 | ★★★ **실제 판매 순위.** 가장 신뢰도 높음 |
| 네이버 데이터랩/검색 | 🔴 차단 (공식·무료지만 도달 못 함) | ★★★ 보조 지표 |
| YouTube Data | 🟢 googleapis 계열 → 도달 가능성 있음 | ★★ 리뷰영상 조회수 |
| Instagram 해시태그 | 트렌드 API 자체가 없음 | ★ **구매 신호가 아님** |
| **토스쇼핑** | ❌ 인앱 전용, 웹 경로 없음 | 사람이 앱에서 직접 볼 것 |

**그록 연동 방식 — 인터페이스를 먼저 고정한다**

```
        content/queue.json   ← 계약(인터페이스). 채우는 주체가 바뀌어도 뒷단은 그대로
              ↑         ↑
   ① 폰 그록 앱 결과      ② scripts/grok_trends.py 가 자동으로 채움
      붙여넣기 (지금)         (정책 열린 뒤 — Phase 8)
              ↓
      make_toon.py "키워드"  →  콘티
```

원칙 1(손으로 1번 성공 → 스크립트화)을 그대로 따릅니다.
**그록이 뽑아준 소재가 실제로 팔리는지 검증되기 전에는 정책도 돈도 쓰지 않습니다.**
질문 템플릿과 사용법은 `docs/SOURCING.md`.

**하지 않기로 한 것**
- 쿠팡 Playwright 스크래핑 — anti-bot 우회는 약관 위반. 걸리면 **파트너스 계정 정지 = 수익 0**.
- 토스 앱 패킷 분석(Charles/Fiddler) — **금융 앱 MITM**. 약관 위반이고 인증서 피닝으로 대개 작동도 안 함.

### 4-6. 기타
- **인스타툰 캐릭터 일관성** — 원안 최대 난이도였으나 **사람이 그리면서 해소**됨.
  레퍼런스는 `assets/character/` 에 유지 (사람이 참고용으로 씀).
- **한글 폰트는 상업적 이용 가능한 것만.** 현재 OFL 3종 확보 (나눔고딕/도현/고딕A1).
- **대량 자동 게시는 스팸 판정 위험.** 주 3~5건이 안전선. 하루 5건 이상 몰아치지 말 것.
- **콘티에 숫자를 지어내면 허위·과장 광고.** `make_toon.py` 검증기가 걸러내지만
  최종 책임은 검수 단계의 사람에게 있음.

### Phase별 상세 (신규·변경분만)

**Phase 9 — 소재 큐 (지금 바로 가능)**
`content/queue.json` 하나를 계약으로 고정합니다. 사람이 채우든 그록 API가 채우든
뒷단(`make_toon.py`)은 안 바뀝니다. 이게 있어야 Phase 8이 **드롭인 교체**가 됩니다.

**Phase 10 — 승인 봇 (원안 항목)**
합성 끝난 대지를 텔레그램으로 받고 '승인' 을 눌러야 발행으로 넘어갑니다.
**봇이 대신 승인하는 게 아니라, 폰으로 편하게 승인하는 것**이 목적입니다.
원칙 2(완전자동 금지)는 그대로 유지됩니다.

**Phase 11 — 콘티 LLM 원복**
원안·이 계획서 모두 콘티 담당은 Claude 입니다. 현재 Gemini 는 임시입니다.
`api.anthropic.com` 은 도달하므로 앤트로픽 키만 있으면 됩니다.
`make_toon.py` 에 프로바이더 분기를 넣고 **같은 키워드로 양쪽 결과를 비교**한 뒤 정합니다.

**Phase 5 — 발행**
링크인바이오 페이지 먼저. 그다음 Graph API. 토큰 갱신 포함. 이미지 공개 URL 호스팅 필요.

**Phase 6 — n8n 이관 (원안의 중앙허브)**
```bash
docker run -d --name n8n -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  -v /절대경로/sale:/data/shared \
  -e N8N_DEFAULT_BINARY_DATA_MODE=filesystem \
  docker.n8n.io/n8nio/n8n
```
로컬 폴더를 `/data/shared` 로 마운트하면 Claude Code가 고친 스크립트를 n8n이 바로 실행합니다.
**폰에서는 불가** — PC 또는 클라우드 호스팅이 필요한 시점입니다.
