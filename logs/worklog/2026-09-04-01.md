## 무엇을 했나
<!-- 한 문단. 코드가 아니라 "무슨 문제를 해결했는지"를 씁니다. -->

사용자가 **프로젝트를 처음 시작할 때의 원본 대화(제미나이)를 다시 가져왔다.** 읽어보니
계획서가 원안에서 조용히 네 가지를 빠뜨리고 있었다 — 시트/노션 트리거, 텔레그램 승인 봇,
LLM 분업 구조, 그록 트렌드 소싱. 이걸 전부 되돌리고, **원안에서 실제로 바뀐 것은
작화를 사람이 맡는 것 하나뿐**임을 계획서 요약에 못박았다.

같이 나온 것 두 가지. 첫째, **네트워크 정책을 실측**해서 원안의 절반이 왜 코드로 안 되는지
숫자로 남겼다. 둘째, **Phase 9 소재 큐**를 새로 만들어 그록 결과가 들어올 자리를 미리 뚫었다.



## 왜 이렇게 했나
<!-- 다른 선택지가 있었다면 왜 그걸 안 골랐는지. 3개월 뒤의 내가 읽습니다. -->

**왜 계획서 복원이 제일 급했나.** 사용자가 "내가 이 기획을 짰는데 맥락이 헷갈린다"고 했다.
원인은 사용자가 아니라 **문서였다.** 머릿속 그림(원안)과 계획서가 어긋나 있으면
헷갈리는 게 당연하다. 코드를 더 짜는 것보다 기준을 맞추는 게 먼저다.

**왜 그록을 API 대신 폰 앱 수동으로 시작하나.** `api.x.ai` 가 막혀 있기도 하지만,
설령 열려 있어도 순서는 같다. **그록이 뽑아준 소재가 실제로 팔리는지 아직 아무도 모른다.**
폰에서 3번 물어보면 며칠 안에 안다. 쓸모없으면 정책도 돈도 안 쓴다.
계획서 원칙 1(손으로 1번 성공 → 스크립트화)이 정확히 이 이야기다.

**왜 `queue.json` 이라는 파일 하나를 먼저 정했나.** 이게 이번 작업의 핵심이다.
채우는 주체(사람 / 그록 API)와 쓰는 쪽(make_toon.py)을 **파일 하나로 끊어놓으면**,
나중에 API를 붙일 때 뒷단 코드를 다시 안 짜도 된다. 인터페이스를 먼저 고정하는 값이 여기 있다.
이걸 안 해두면 Phase 8 에서 소재 수집 코드와 콘티 코드를 같이 뜯어고쳐야 한다.

**왜 그록 평가를 뒤집었나.** 8/31 조사에서 X를 "비용 대비 약함"으로 깎았는데,
그건 **X API 직접 구독(월 $100~)** 기준이었다. 그록을 경유하면 전제가 다르다.
원안의 판단(그록=트렌드 소싱 보조)이 맞았고, 조사가 다른 걸 재고 있었다.

**왜 Gemini→Claude 원복을 지금 안 하고 Phase 11 로 미뤘나.** 앤트로픽 키가 없다.
다만 **모순을 문서에 드러내는 것**은 지금 해야 한다. 안 그러면 다음 세션의 내가
"코드가 Gemini니까 Gemini가 맞나 보다" 하고 굳혀버린다.



## 막힌 점 / 배운 점
<!-- 에러 메시지 원문, 삽질한 시간, 해결한 방법. 여기가 이 일지에서 제일 값어치 있는 칸입니다. -->

**1. 네트워크 정책 실측 — 이번 세션에서 가장 값어치 있는 발견.**
8개 호스트를 찔러보고 프록시 상태까지 확인했다.
```
gateway answered 403 to CONNECT (policy denial or upstream failure)
  host: api.x.ai:443 / api.openai.com:443 / api.telegram.org:443
        slack.com:443 / api-gateway.coupang.com:443 / graph.facebook.com:443
```
도달하는 건 `api.anthropic.com`(401=도달) 과 googleapis 둘뿐.
→ 배운 것: **이건 버그가 아니라 환경 생성 시 고른 설정이다.** 즉 사용자가 열 수 있다.
그동안 "차단됐다"로만 적어놨지 **고칠 수 있는 것인 줄 몰랐다.** 이걸 몰라서
Phase 5·8 을 "불가능"으로 취급하고 있었는데, 실제로는 "설정 한 번"이다.

**2. `api.anthropic.com` 이 도달한다는 걸 이제야 확인했다.**
원안도 계획서도 콘티 담당은 Claude 인데 코드는 Gemini 로 굴러가고 있었다.
Phase 0 에서 "키가 Gemini뿐"이라 갈아탄 게 **문서를 안 고친 채 굳어버린 것.**
→ 배운 것: 임시 조치를 할 땐 **임시라고 문서에 적어야 한다.** 안 적으면 그게 최종이 된다.

**3. 한글 표가 어긋났다.**
```
⬜    상    겨울 온열매트                0일     한파로...
⬜    중    무선 핸디 청소기              0일     차량...
```
`f"{keyword:<22}"` 가 **글자 수**로 세는데 한글은 화면에서 **2칸**을 먹는다.
`unicodedata.east_asian_width` 로 폭을 계산하는 `pad()` 를 따로 만들어 해결했다.
→ 한글 CLI 를 만들 때마다 나올 문제라 `selftest` 에 회귀 테스트로 박아뒀다.

**4. 이번엔 함정을 하나 피했다.** `queue.py` 를 만들고 `selftest` 에 큐 검증 9개를
바로 추가했다. 안 넣었으면 스키마가 조용히 깨져도 몰랐을 것이다. 32/32 통과.

**5. 아직 확인 못 한 것.** 그록 API의 **Live Search** 옵션명·단가를 실물로 확인하지 못했다.
차단돼 있어서 문서로만 적었다. 외워서 쓰면 틀릴 위험이 있어 **정책이 열리면 실측**하기로 남겨뒀다.
