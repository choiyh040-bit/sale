## 4. 반드시 알아야 할 제약 (여기서 사업이 망가집니다)

### 4-0. ★네트워크 정책 — 현재 최대 병목★

이 컨테이너의 아웃바운드는 **정책 프록시**를 거칩니다. 허용되지 않은 호스트는
`403 to CONNECT (policy denial)` 로 막힙니다. **실측 결과 (2026-09-03):**

| 호스트 | 용도 | 결과 |
|---|---|---|
| `api.anthropic.com` | Claude API (콘티) | 🟢 **도달** |
| `generativelanguage.googleapis.com` | Gemini API | 🟢 **도달** |
| `api.x.ai` | **그록** — 트렌드 소싱 | 🔴 차단 |
| `api.openai.com` | GPT — 소재 앵글 | 🔴 차단 |
| `api.telegram.org` | 승인 봇 | 🔴 차단 |
| `slack.com` | 승인 봇(대안) | 🔴 차단 |
| `api-gateway.coupang.com` | 파트너스 — 링크·순위 | 🔴 차단 |
| `graph.threads.net` | **스레드 발행** | 🔴 차단 (→ Actions 로 우회) |

**이건 버그가 아니라 환경 생성 시 고른 설정입니다.** 즉 **바꿀 수 있습니다.**

> claude.ai/code → **환경(Environment) 설정 → 네트워크 정책**에서 허용 도메인을 넓힙니다.
> 문서: https://code.claude.com/docs/en/claude-code-on-the-web

**정책을 열면 Phase 6·8·10 이 풀립니다.** (Phase 5 발행은 Actions 로 이미 길이 있습니다) 반대로 열지 않으면
이 컨테이너만으로는 "콘티 만들고 그림 얹어서 사람이 직접 스레드에 올리는 것"까지가 한계입니다.
**그러나 발행은 GitHub Actions 로 우회됩니다** — 핫딜 계정이 이미 그 방식으로 돌고 있습니다.
정책을 여는 것은 그록·쿠팡(소재 수집)을 위한 것이고, **발행의 전제조건은 아닙니다.**

- 진단: `curl -sS "$HTTPS_PROXY/__agentproxy/status"` → `recentRelayFailures` 에 차단 사유가 남습니다.
- **우회 시도 금지.** TLS 검증을 끄거나 프록시를 벗어나려 하지 않습니다.

### 4-1. 제휴 고지는 법적 의무
쿠팡파트너스 링크가 들어간 게시물에는 **수수료를 받는다는 고지 문구**가 반드시 들어가야 합니다.
표시광고법 / 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 대상입니다.

- 문구는 **본문 캡션 첫 부분** 또는 이미지 안에, 잘 보이게.
- "더보기" 안에 숨기거나, 해시태그 무더기 뒤에 끼워넣으면 위반 소지.
- 표준 문구: `이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따라 일정액의 수수료를 제공받습니다.`
- 토스 쉐어링크도 자체 약관의 고지 요건을 별도 확인할 것.

### 4-2. 링크 동선 — 스레드로 바꾼 이유 ★중요★

**이 전환의 이유가 전부 여기 있습니다.**

인스타는 캡션·댓글의 URL이 클릭되지 않아, `게시물 → 프로필 링크 → 링크인바이오 → 제휴 링크`
라는 3단 동선을 억지로 만들어야 했습니다. 단계마다 사람이 떨어져 나갑니다.

**스레드는 첫 댓글 링크가 클릭됩니다.** (`link` 저장소에서 실제 게시로 검증, 2026-10-26)

```
스레드:  툰 캐러셀  →  첫 댓글의 제휴 링크  →  구매      (2단)
인스타:  게시물  →  프로필  →  링크인바이오  →  제휴 링크  (4단)
```

- **링크인바이오가 필수에서 빠졌습니다.** 상품이 여러 개 쌓였을 때 모아두는 용도로만 나중에 고려합니다.
- **페이스북 페이지 연결도 필요 없어졌습니다.** (4-3절)
- 고지 문구는 여전히 필수입니다 — 4-1절. 댓글이 아니라 **본문에** 넣습니다.
  댓글은 접힐 수 있어서 고지를 숨긴 것으로 볼 여지가 생깁니다.

> ~~인스타: 링크인바이오 먼저 만들어야 함~~ → 2026-10-26 전환으로 폐기.

### 4-3. Threads API 요건

- 스레드 계정 + Meta 개발자 앱 + `threads_basic` · `threads_content_publish` 권한.
- **페이스북 페이지 연결이 필요 없습니다.** 인스타 Graph API 와 가장 크게 다른 점입니다.
- 액세스 토큰은 만료됨 → 갱신 로직 필요.
- 이미지는 로컬 파일이 아니라 **공개 URL** 을 요구함 → 이미지 호스팅 경로 필요.
  (인스타와 같은 제약이라 이 항목은 그대로 남습니다)
- **발행 실행은 GitHub Actions 에서 합니다.** 이 컨테이너는 `graph.threads.net` 이 차단입니다.

> ⚠️ **한도·형식은 외워서 쓰지 말 것.** 하루 발행 한도, 캐러셀 장수, 요청 형식은
> `link` 저장소의 **실제 게시로 검증된 코드**(`scripts/post_threads.py`)를 기준으로 삼습니다.

### 4-8. 콘텐츠 방향 (2026-10-29)

**첫 한 달은 간보기.** 제휴 링크 없는 **순수 일상툰**만 올린다.

| | |
|---|---|
| 형식 | **4컷** 캐러셀 |
| 빈도 | **주 1회** |
| 그림체 | 최대한 **단순하고 귀엽게** |
| 톤 | 소소한 일상. 개그도 아니고 삭막하지도 않게 |

#### ⬜ 컨셉은 아직 못 정했다

아래는 **검토했으나 채택되지 않은 안**이다. 지우지 않고 남기는 이유는
같은 걸 또 제안하지 않기 위해서다.

| 안 | 왜 떨어졌나 |
|---|---|
| 소재 목록 10개 (넵 / 일요일 밤 / 공용 냉장고…) | **다들 쓴 것.** 검색하면 다 나온다 |
| 포맷 6개 (사물 시점 / 번역기 / 도감 / 장르 비틀기…) | 이것도 이미 있는 것들 |
| 「마지막 잎새」 — 화분이 시들어 죽음 | **너무 삭막하다.** 원하는 건 소소한 일상툰 |
| 「오늘의 작은 것」 — 마지막 컷 고정 + 화분 동료 | 마음에 안 듦 |

**사용자가 말한 것**: "엄청 신박한 건 아니어도 되지만 **뭔가 킥이 있으면** 좋겠다."
그리고 **"차라리 대놓고 하는 광고는 콘티를 짜겠는데"** — 순수 창작보다
**제약이 있는 기획이 더 쉽다**는 뜻이다. 이게 중요한 단서다.

#### 참고: 떨어진 안에서 살릴 만한 것

1. **마지막 컷은 늘 같다**: `오늘의 작은 것` + 그날 좋았던 사소한 것 하나.
   - 매번 "뭘로 끝내지" 를 고민하지 않아도 된다.
   - 독자가 자기 것도 말하고 싶어지는 포맷이라 **댓글이 붙는다.**
   - 10편에 1~2편쯤은 `오늘의 작은 것: 없음` 으로 끝내도 된다.
     매 편 따뜻하기만 하면 가짜 같아진다. 그런 편이 나머지의 온기를 진짜로 만든다.
2. **책상 위 화분**: 말 없는 동료. 주인공이 아무한테도 못 하는 말을 화분한테만 한다.
   - **죽이지 않는다.** 처음엔 잎이 떨어지는 안을 냈다가 "너무 삭막하다" 로 폐기됐다.
     힘든 날 잎 하나 떨어뜨리는 정도까지만.

**소재 만드는 법**: 하루 한 번 폰 메모에 "오늘 나 혼자 속으로 생각한 것" 을 한 줄 적는다.
거창한 스토리를 짜낼 필요가 없다.

**그 사이에는 글만 올린다.** 스레드는 원래 글 중심이라 그림 없는 한 줄 글은 부담이 0이다.
주 2~3회 올리고, 반응 좋은 글이 다음 툰 소재가 된다. 그림 그리기 전에 뭐가 먹히는지 먼저 안다.

**한 달 뒤 판단 기준**: 4편을 다 올렸는가.
- 다 올렸다 → 주 2회로 올린다
- 2~3편 → 주 1회 유지. 정상이다
- 1편 이하 → 빈도가 아니라 **4컷을 2컷으로** 줄인다

> **상품 툰은 하지 않는다.** 팔로워 1,000명 전후까지 보류 (4-7절).
> 9월에 만든 상품 콘티 3건(온열매트·핸디청소기·가습기)은 2026-10-29 폐기했다.
> 인스타 전제로 만든 것이고 계절·기획이 지났다. `toon.json` 은 기록으로만 남겼다.

> ⚠️ `scripts/make_toon.py` 는 **상품 키워드**를 받는 상품 툰용이다.
> 일상툰은 입력이 "상품" 이 아니라 "오늘 있었던 일" 이라 지금 코드로는 안 나온다.
> 당분간 **콘티는 사람이 직접** 짠다(주간 브레인스토밍). 원칙 1 — 손으로 1번 성공한 뒤에
> 스크립트화한다. 일상툰 콘티 생성기는 그때 만든다.
