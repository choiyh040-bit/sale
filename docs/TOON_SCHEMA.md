# toon.json 스키마 (v1)

인스타툰 1편의 **모든 정보**를 담는 단일 파일. 파이프라인 전 단계가 이 파일 하나를 주고받는다.

```
[기획] → toon.json 생성 → [작화] cuts[].image_prompt 사용
                        → [합성] cuts[].dialogue + balloon 사용
                        → [발행] caption + hashtags + disclosure 사용
```

- 위치: `content/<id>/toon.json`
- 실물 예시: `content/2026-08-31-winter-heatmat/toon.json` ← **손으로 만든 1호**

---

## 필드

### `meta`
| 키 | 설명 |
|---|---|
| `id` | 폴더명과 동일. `YYYY-MM-DD-영문슬러그` |
| `keyword` | 입력 키워드 |
| `made_by` | `hand` / `claude` / `gemini` — 누가 만들었는지 |
| `schema_version` | 스키마 버전. 구조를 바꾸면 올린다 |
| `status` | `draft` → `art_done` → `composed` → `approved` → `published` |

### `product`
상품과 제휴 정보. `affiliate.landing` 이 `linkinbio` 인 이유는
**인스타 캡션·댓글의 URL은 클릭이 안 되기 때문**이다. 반드시 프로필 링크로 보내야 한다.

### `plan`
기획 의도. `persona` / `pain` / `hook` / `angle` / `cta`.
**작화나 합성은 이 칸을 안 쓴다.** 사람이 "이 콘티가 왜 이렇게 나왔는지" 판단하는 용도이고,
나중에 잘 되는 후킹 패턴을 역추적할 때 쓴다.

### `character`
| 키 | 설명 |
|---|---|
| `ref` | 레퍼런스 이미지 경로. 전 컷에 동일하게 적용 |
| `prompt_prefix` | **모든 컷의 image_prompt 앞에 붙는 고정 문구** |

캐릭터 일관성이 이 프로젝트 최대 기술 난이도라, 화풍·인물 묘사를 컷별로 흩어놓지 않고
여기 한 곳에 모았다. 얼굴이 바뀌면 여기만 고치면 된다.

### `format`
`canvas`: `[1080, 1350]` (4:5). 인스타 피드에서 세로 공간을 가장 많이 차지하는 비율.
`cut_count`: 캐러셀 최대 10장이므로 그 이하.

### `cuts[]`
| 키 | 쓰는 곳 | 설명 |
|---|---|---|
| `n` | — | 컷 번호 (1부터) |
| `role` | 사람 | `hook` / `problem` / `escalation` / `turn` / `solution` / `cta` |
| `scene` | **사람** | 한국어 상황 설명. 검수할 때 읽는 칸 |
| `dialogue` | **합성** | 말풍선에 들어갈 대사 |
| `balloon` | **합성** | `pos`(9분할 위치) + `tail`(꼬리 방향) |
| `image_prompt` | **작화** | 영문. `character.prompt_prefix` 뒤에 이어붙인다 |

`scene`(한국어)과 `image_prompt`(영문)를 나눈 이유: 사람이 검수하는 언어와
이미지 모델이 먹는 언어가 다르다. 하나로 합치면 둘 다 어정쩡해진다.

### `caption` / `hashtags` / `disclosure`
`disclosure` 는 **필수**다. 비우면 안 된다.
쿠팡파트너스 고지 문구는 표시광고법·공정위 추천보증 심사지침 대상이고,
"더보기" 안에 숨기면 위반 소지가 있으므로 **캡션 앞부분**에 노출한다.

## 컷 구성 원칙 (1호에서 나온 것)

6컷 기준 `hook → problem → escalation → turn → solution → cta`.

- **1컷에서 안 잡히면 끝이다.** 상품 얘기 말고 **공감되는 장면**으로 연다.
  (1호: 상품 소개가 아니라 "난방비 고지서 보고 굳은 표정"으로 시작)
- **대사는 짧게.** 폰 화면에서 읽힌다. 한 컷에 한 줄이 기본.
- **5컷(solution)은 대사를 비워도 된다.** 1호는 `…………` 만 넣었다.
  표정으로 말하는 컷이 있어야 리듬이 산다.
- **상품을 칭찬하지 않는다.** 주인공이 편해진 모습만 보여준다.

## ⚠️ 절대 넣으면 안 되는 것

**검증 안 된 숫자.** "난방비 10만원 → 3만원", "보일러보다 80% 저렴" 같은
구체적 절감 수치를 지어내면 **허위·과장 광고**가 된다.

1호에서도 이 이유로 마지막 컷을 숫자 없이
"집은 추워도 이불 속은 여름이야" 라는 **체감 표현**으로 끝냈다.
수치를 쓰려면 실제 제품 사양이나 공인된 근거가 있어야 한다.
