## 무엇을 했나
<!-- 한 문단. 코드가 아니라 "무슨 문제를 해결했는지"를 씁니다. -->

사용자가 **핫딜 계정 쪽(`link` 저장소) 자동화를 끝내고** 돌아왔다. 그쪽에서 정한 두 계정의
관계를 `CLAUDE.md` 에 메모로 남겨뒀는데, **그 메모가 `main` 에만 있어서 작업 브랜치의
작업 기준에는 안 들어와 있었다.** 세션 시작 때 자동 로드된 기준에도 빠져 있었다.
브랜치를 합치고, 메모 내용에 맞춰 **발행처를 인스타 → 스레드로 전환**했다.



## 왜 이렇게 했나
<!-- 다른 선택지가 있었다면 왜 그걸 안 골랐는지. 3개월 뒤의 내가 읽습니다. -->

**왜 스레드인가.** 링크 때문이다. 인스타는 캡션·댓글 URL 이 클릭되지 않아
`게시물 → 프로필 → 링크인바이오 → 제휴 링크` 4단을 만들어야 했다. 단계마다 사람이 빠진다.
스레드는 **첫 댓글 링크가 클릭된다** — `link` 저장소에서 실제 게시로 검증된 사실이다.
동선이 2단으로 줄고, **링크인바이오와 페이스북 페이지 요건이 동시에 사라졌다.**

**왜 `link` 코드를 복사해 오고 런타임으로 묶지 않는가.** 사용자가 메모에 적은 원칙이
"저장소·대화는 섞지 않는다"다. 런타임 의존을 만들면 `link` 를 고칠 때 툰 계정 발행이
같이 깨지고, 그러면 "따로 운영한다"는 결정이 무의미해진다. 복사하고 **가져온 커밋 해시를
남겨서** 나중에 의도적으로 다시 맞출 수 있게 하는 쪽이 맞다.

**왜 정책 열기를 최우선에서 내렸나.** 발행이 정책에 걸려 있다는 전제가 틀렸기 때문이다.
아래 '배운 점' 참조. 정책은 이제 **소재 수집(그록·쿠팡)** 을 위한 것이고, 발행의 전제가 아니다.

**왜 고지 문구를 댓글이 아니라 본문에 넣게 적었나.** 제휴 링크는 첫 댓글에 가지만,
댓글은 접힐 수 있다. 접히는 자리에 고지를 넣으면 "숨겼다"고 볼 여지가 생긴다(4-1절).



## 막힌 점 / 배운 점
<!-- 에러 메시지 원문, 삽질한 시간, 해결한 방법. 여기가 이 일지에서 제일 값어치 있는 칸입니다. -->

**1. 메모를 못 보고 있었다 — 이게 이번 세션 최대 문제였다.**
사용자가 "깃에 메모 써놨는데 읽혀?"라고 물어서야 알았다. `main` 에 있고 내 작업 브랜치는
`claude/sale-da6dga` 라서, SessionStart 훅이 로드한 `CLAUDE.md` 에는 메모가 없었다.
```
main 에만:        사용자 메모 (계정 연결 + 핸들)
내 브랜치에만:    원안 복원, Phase 9 소재 큐, 일지 3건, 콘티 3건
```
→ 배운 것: **브랜치가 갈라지면 작업 기준도 갈라진다.** 사용자가 웹/다른 세션에서 `main` 에
직접 커밋할 수 있으므로, **세션 초반에 `git fetch` 로 `main` 쪽 변화를 먼저 확인**해야 한다.
물어봐 주지 않았으면 메모를 무시한 채로 계속 작업했을 것이다.

**2. 열흘 전 리포트의 전제가 틀렸다.**
발행 방식 리포트에서 네트워크 정책을 병목 2번으로 꼽고 "열어야 자동 발행이 된다"고 썼다.
그런데 **GitHub Actions 러너는 이 컨테이너 정책 밖**이다. 핫딜 계정이 이미 그렇게 돌고 있었다.
→ 배운 것: **"이 컨테이너에서 안 된다"를 "불가능하다"로 번역하면 안 된다.**
실행 장소를 바꾸는 선택지를 먼저 봐야 했다. 리포트가 사용자 결정에 쓰이는 문서였으므로
틀린 전제의 값이 더 컸다.

**3. 스레드 링크 위치를 잘못 알고 있었다.**
나는 "스레드는 본문 링크가 클릭된다"고 설명했는데, 메모에는 **첫 댓글 링크**가 클릭되고
그걸로 실제 게시 검증까지 됐다고 적혀 있다. 실측된 쪽을 기준으로 삼았다.
→ API 한도·형식도 같은 이유로 **외워서 쓰지 말고 `link` 의 검증된 코드를 기준으로** 하라고
계획서에 못박았다.

**4. 지난 세션 이후 컨테이너가 또 바뀌어 있었다.**
`python3` 이 3.11 을 가리키는데 패키지는 3.13 에 깔려 `PIL` import 가 실패했다.
`/usr/bin/python3.13` 로 실행하면 정상. 이번 세션 작업은 전부 그걸로 돌렸다.
**스크립트가 쓸 파이썬을 고정하는 문제는 아직 안 고쳤다.**

**5. 아직 확인 못 한 것.** `link` 저장소를 이 세션에 붙이지 않아
`post_threads.py` 를 **실제로 읽어보지 못했다.** 계획서에 "복사해 온다"고만 적어둔 상태다.
