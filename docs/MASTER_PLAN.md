## 한 장 요약 (세션마다 자동 로드되는 부분)

- **무엇**: 쿠팡파트너스 / 토스 쉐어링크 제휴 링크로 수익을 내는 **인스타툰 계정**의 제작 파이프라인.
- **어떻게**: 키워드 1개 입력 → 후킹 기획 → 4~8컷 콘티(JSON) → 작화 → 말풍선 합성 → **사람 검수** → 인스타 발행.
- **원칙 3가지**
  1. **손으로 1번 성공 → 스크립트화 → 자동화.** 순서를 뒤집지 않는다.
  2. **완전자동 금지, 반자동이 목표.** 발행 직전 검수 단계는 끝까지 남긴다.
  3. **한 Phase = 혼자서도 돌아가는 결과물 1개.** 반쪽짜리로 다음으로 넘어가지 않는다.
- **작업 환경**: **핸드폰 + Claude Code 웹(원격 컨테이너).** 로컬 PC가 아니다.
  코드는 전부 컨테이너에서 실행하고, 결과는 git으로만 남는다. 컨테이너는 세션이 끝나면 사라진다.
- **현재 위치**: `docs/TODAY.md` 상단의 "현재 Phase" 를 기준으로 삼는다.
- **절대 규칙**: API 키는 `.env` 에만. 절대 커밋 금지. 게시물에는 제휴 고지 문구 필수.

## 2. 시스템 구조

```
[입력]  keywords.csv  (상품명 / 제휴링크 / 후킹 각도 메모)
   │
   ▼
[1] 기획      키워드 → 후킹 앵글 + 타깃 페르소나 + 핵심 소구점
   │
   ▼
[2] 콘티      → toon.json  (컷별 대사 + 영문 image_prompt + 말풍선 위치)
   │
   ▼
[3] 작화      image_prompt → 컷 이미지 N장  (캐릭터 일관성 유지)
   │
   ▼
[4] 합성      Python + Pillow → 말풍선/대사 오버레이 → 1080x1350 PNG
   │
   ▼
[5] 검수 ★    output/ 폴더 또는 텔레그램으로 확인 → 사람이 승인
   │
   ▼
[6] 발행      Instagram Graph API 캐러셀 업로드 + 캡션 + 제휴 고지
```

★ 표시 = **절대 자동화하지 않는 단계.** 계정 품질과 규정 리스크를 여기서 막습니다.

## 3. 도구 선택 (2026년 8월 기준으로 갱신)

> ⚠️ 참고한 Gemini 대화의 모델 이름(Claude 3.7 Sonnet, GPT-4o, o3-mini)은 **이미 구버전**입니다.
> 아래가 현재 기준입니다.

| 역할 | 도구 | 비고 |
|---|---|---|
| 실행 환경 | **Claude Code 웹 (원격 컨테이너)** | 핸드폰에서 접속. 코드 실행·파일 생성 전부 여기서 |
| 콘티/대본 생성 | **Claude Opus 5** (`claude-opus-5`) | $5 / $25 per 1M 토큰. 한국어 구어체·스토리 구성 강점 |
| 대량 반복 생성 | **Claude Sonnet 5** (`claude-sonnet-5`) | $2 / $10. 콘티 품질이 안정되면 여기로 내려서 비용 절감 |
| 단순 분류/태깅 | **Claude Haiku 4.5** (`claude-haiku-4-5`) | $1 / $5 |
| 작화 | 이미지 생성 API (Replicate 등) | **상업적 이용 라이선스 반드시 확인** |
| 합성 | Python + Pillow | 로컬, 무료 |
| 오케스트레이션 | n8n (Docker, 로컬) | **Phase 6에서 도입.** 그전까지는 파이썬 스크립트로 충분 |
| 발행 | Instagram Graph API | 무료, 단 계정 요건 있음 (아래 참조) |

### 비용 추산 (게시물 1건)

- 콘티 생성 (Opus 5): 입력 2K + 출력 2K 토큰 ≈ **$0.06 (약 90원)**
- 콘티 생성 (Sonnet 5로 내리면): ≈ **$0.024 (약 35원)**
- 이미지 6컷: 모델·해상도에 따라 **$0.02 ~ $0.25 (약 30~350원)**
- 합성·발행: 0원

→ **건당 대략 100~500원.** 월 30건이면 3천~1만5천원 수준.

## 4. 반드시 알아야 할 제약 (여기서 사업이 망가집니다)

### 4-1. 제휴 고지는 법적 의무
쿠팡파트너스 링크가 들어간 게시물에는 **수수료를 받는다는 고지 문구**가 반드시 들어가야 합니다.
표시광고법 / 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 대상입니다.

- 문구는 **본문 캡션 첫 부분** 또는 이미지 안에, 잘 보이게.
- "더보기" 안에 숨기거나, 해시태그 무더기 뒤에 끼워넣으면 위반 소지.
- 표준 문구: `이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따라 일정액의 수수료를 제공받습니다.`
- 토스 쉐어링크도 자체 약관의 고지 요건을 별도 확인할 것.

### 4-2. 인스타그램 링크의 현실 ★중요★
> 참고한 Gemini 답변에는 "첫 댓글에 제휴 링크 삽입" 이라고 되어 있는데, **이건 실무에서 잘 안 됩니다.**

- 인스타그램은 **캡션과 댓글의 URL을 클릭 가능하게 만들지 않습니다.** 그냥 텍스트로 보입니다.
- 유일하게 클릭되는 링크는 **프로필의 링크(링크인바이오)** 와 스토리 링크 스티커입니다.
- 따라서 실제 동선은:
  `게시물 → "프로필 링크 확인" 유도 → 링크인바이오 페이지 → 개별 제휴 링크`
- **Phase 5 이전에 링크인바이오 페이지부터 만들어야 합니다.** (Linktree 또는 자체 정적 페이지)
- 이 구조가 없으면 게시물을 아무리 많이 올려도 클릭이 0입니다.

### 4-3. Instagram Graph API 요건
- 계정이 **프로페셔널 계정(비즈니스 또는 크리에이터)** 이어야 함.
- **Facebook 페이지와 연결**되어 있어야 함.
- Meta 개발자 앱 생성 + `instagram_content_publish` 권한 승인 필요 (앱 심사 있음).
- **하루 발행 한도 25건.** 캐러셀은 최대 10장.
- 액세스 토큰은 만료됨 → 장기 토큰 갱신 로직 필요 (Phase 5에서 처리).

### 4-4. 작업 환경 제약 (핸드폰 + 원격 컨테이너)
- **로컬 PC가 없다.** 가상환경 만들고 `pip install` 하고 스크립트 돌리는 건 전부 원격 컨테이너에서 한다.
- **컨테이너는 세션이 끝나면 사라진다.** 남기고 싶은 건 반드시 **커밋 + 푸시**해야 한다.
  설치한 패키지도 매 세션 다시 깔린다(느리지만 자동).
- **API 키는 `.env` 에 두면 세션마다 날아간다.** 환경 설정의 **환경변수**로 넣어야 유지된다.
  절대 채팅창에 붙여넣지 않는다 — 대화 기록에 영구히 남는다.
- **컨테이너에서 막히는 사이트가 있다.** 확인된 것:
  - `aistudio.google.com` (Gemini 키 발급 페이지) → 차단. **폰 브라우저로** 발급받을 것.
  - `share.gemini.google` → 차단.
  - `generativelanguage.googleapis.com` (Gemini API), `api.anthropic.com` → **정상 도달.**
- **생성된 이미지를 폰에서 보는 법**: GitHub에서 보거나, 채팅으로 파일을 받는다.
- **Phase 6(n8n Docker)은 폰에서 불가능하다.** 그 시점에 PC를 쓰거나 클라우드 호스팅으로 갈아타야 한다.
  → Phase 5까지는 파이썬만으로 가므로 당분간 문제없다.

### 4-5. 기타
- **이미지 생성 모델의 상업적 이용 라이선스**를 모델별로 확인. 수익화 계정이므로 필수.
- **인스타툰 캐릭터 일관성**이 이 프로젝트 최대 기술 난이도. 컷마다 얼굴이 바뀌면 계정이 죽습니다.
  → 캐릭터 레퍼런스 이미지를 `assets/character/` 에 고정하고 전 컷에 동일 레퍼런스를 씁니다.
- **대량 자동 게시는 스팸 판정 위험.** 주 3~5건이 안전선. 하루 5건 이상 몰아치지 말 것.

## 5. Phase 로드맵

각 Phase는 **그것만으로 돌아가는 결과물**을 남깁니다. 반쪽으로 다음에 가지 않습니다.

| Phase | 이름 | 완료 조건 (Definition of Done) | 예상 |
|---|---|---|---|
| **0** | 환경 세팅 | 컨테이너에서 `python scripts/hello.py` 가 돌고 LLM 응답을 받음 | 1일 |
| **1** | 콘티 생성기 | `python scripts/make_toon.py "키워드"` → 유효한 `toon.json` 출력 | 2~3일 |
| **2** | 말풍선 합성기 | 샘플 이미지 + toon.json → 대사 얹힌 1080x1350 PNG 생성 | 3~5일 |
| **3** | 작화 연결 | image_prompt → 실제 컷 이미지 생성, **캐릭터 얼굴 일관성 확보** | 5~7일 |
| **4** | 로컬 원클릭 | `python run.py "키워드"` 한 줄로 output/ 에 완성 게시물 세트 | 2~3일 |
| **5** | 발행 | 링크인바이오 준비 + Graph API로 캐러셀 1건 실제 업로드 성공 | 5~7일 |
| **6** | n8n 이관 | Docker n8n + 볼륨 마운트, 시트 입력 → 검수 알림까지 자동 ⚠️폰 불가 | 5~7일 |
| **7** | 운영·최적화 | 성과 지표 수집, 소재 큐 운영, 후킹 A/B | 상시 |

### Phase별 상세

**Phase 0 — 환경 세팅**
Python 가상환경, `.gitignore`, `.env.example`, 의존성 설치. Claude API 키 발급 및 호출 1회 성공.

**Phase 1 — 콘티 생성기**
Claude API로 키워드 → 구조화된 JSON. 스키마를 먼저 고정합니다.
```json
{
  "hook": "매번 이거 찾느라 스트레스였는데",
  "product": "상품명",
  "cuts": [
    {"n": 1, "dialogue": "대사", "image_prompt": "webtoon style, ...", "balloon": "top-left"}
  ],
  "caption": "본문 캡션",
  "disclosure": "이 게시물은 쿠팡 파트너스 활동의 일환으로..."
}
```
출력이 항상 이 스키마를 지키게 하는 것이 이 Phase의 핵심입니다.

**Phase 2 — 말풍선 합성기**
Pillow로 한글 폰트 렌더링. 한글 줄바꿈이 가장 자주 깨지는 지점입니다.
말풍선 크기를 텍스트에 맞춰 자동 조절하고, 폰트는 **상업적 이용 가능한 것**으로 (예: 프리텐다드, 나눔).

**Phase 3 — 작화 연결**
캐릭터 일관성이 전부입니다. 레퍼런스 이미지 고정 + 시드 고정 + 동일 프롬프트 접두어.
컷 하나가 이상하면 그 컷만 재생성할 수 있게 만듭니다.

**Phase 4 — 로컬 원클릭**
1~3을 이어붙입니다. 중간 산출물을 전부 파일로 남겨서 어디서 깨졌는지 볼 수 있게 합니다.

**Phase 5 — 발행**
링크인바이오 페이지 먼저. 그다음 Graph API. 토큰 갱신 포함.

**Phase 6 — n8n 이관**
```bash
docker run -d --name n8n -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  -v /절대경로/sale:/data/shared \
  -e N8N_DEFAULT_BINARY_DATA_MODE=filesystem \
  docker.n8n.io/n8nio/n8n
```
로컬 폴더를 `/data/shared` 로 마운트하면 Claude Code가 고친 스크립트를 n8n이 바로 실행합니다.

**Phase 7 — 운영**
게시물별 성과를 시트에 쌓고, 잘 되는 후킹 패턴을 콘티 프롬프트에 역주입합니다.

## 6. 이 프로젝트의 작업 방식

1. 세션을 열면 이 요약과 `docs/TODAY.md` 가 자동으로 로드됩니다.
2. 오늘 할 일은 `docs/TODAY.md` 의 **P(Plan)** 에 적습니다.
3. 작업하면서 **D(Do)** 에 기록합니다.
4. 커밋할 때마다 `logs/worklog/` 에 일지가 자동 생성됩니다.
5. Phase가 끝나면 `/log` 로 마일스톤 일지를 남기고 `/today` 로 다음 날 계획을 세웁니다.
