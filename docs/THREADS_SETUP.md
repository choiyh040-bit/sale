## 먼저 — 무엇이 무엇과 연결되는가

이걸 잘못 알면 계속 헷갈립니다.

```
Meta 앱  ──(테스터 등록 + 권한 수락)──  스레드 계정      ← 진짜 연결
Meta 앱  ──(토큰을 복사해 붙여넣기)───  GitHub 저장소    ← 연결 아님. 복사일 뿐
```

- **앱은 GitHub 저장소를 전혀 모릅니다.** 앱이 토큰을 만들어 주고, 그 토큰을 저장소 Secret에 넣는 것뿐입니다.
- 앱이 실제로 묶이는 대상은 **스레드 계정**입니다.
- 그래서 계정이 둘이면 **토큰도 둘, 넣는 저장소도 둘**입니다.

## 빠른 길 — 앱을 새로 만들지 않는 방법

Threads API는 **앱 하나에 여러 계정을 테스터로 넣고 계정별로 토큰을 따로** 발급할 수 있습니다.
이미 있는 `오늘의 할인 게시` 앱을 그대로 쓰면 **4단계부터** 하면 됩니다.

대신 앱 이름이 계정과 안 맞아 나중에 헷갈릴 수 있습니다. **계정을 따로 운영하기로 했으니
앱도 따로 만드는 쪽(아래 전체 절차)을 권합니다.** 화면에서 테스터 목록에 두 계정이
같이 보이는지는 직접 확인해 보세요.

---

## 1. Meta 개발자 계정 (이미 했으면 건너뜀)

1. https://developers.facebook.com 에 페이스북 계정으로 로그인합니다.
2. 오른쪽 위 **시작하기** → 휴대폰 인증 → 개발자 등록을 마칩니다.

> 핫딜 때 이미 하셨다면 그대로 쓰면 됩니다. 개발자 계정은 하나로 앱을 여러 개 만들 수 있습니다.

## 2. 앱 만들기

1. **내 앱 → 앱 만들기**
2. 사용 사례에서 **Threads API 액세스**를 고릅니다.
3. 앱 이름은 **`toon 게시`** 처럼 계정이 바로 떠오르는 이름으로 합니다.
   (핫딜 앱이 `오늘의 할인 게시` 이므로 구분이 됩니다)

## 3. 권한 켜기 — 3개

1. 앱 대시보드 → **사용 사례 → Threads API 액세스 → 사용자 지정(설정)**
2. 권한에서 아래 셋을 **추가**합니다.

| 권한 | 왜 필요한가 |
|---|---|
| `threads_basic` | 기본. 내 계정 정보를 읽습니다 |
| `threads_content_publish` | 툰 캐러셀을 올립니다 |
| `threads_manage_replies` | **첫 댓글에 제휴 링크를 답니다 — 빠지면 수익 동선이 끊깁니다** |

> 세 번째를 빠뜨리면 툰은 올라가는데 **링크가 안 달립니다.** 꼭 확인하세요.

**앱 심사는 필요 없습니다.** 내 계정에만 올리는 앱은 개발 모드 그대로 씁니다.

## 4. 툰 계정을 테스터로 넣기

1. 앱 대시보드 → **앱 역할 → 역할 → 사람 추가** → **Threads 테스터** →
   `scribble1013` 을 넣습니다.
2. **스레드 앱에서 초대를 수락합니다.** 실제 경로는 이렇습니다 (2026-10-27 확인):

   ```
   설정  →  설정 더보기  →  웹사이트 권한  →  상단 탭 "초대(Invites)"
   ```

   `계정` 아래가 아니라 **`설정 더보기`** 안에 있습니다. 그리고 웹사이트 권한에
   들어가면 **상단에 탭이 몇 개** 있는데, 그중 `초대` 탭을 눌러야 보입니다.

> 🚨 **초대가 `삭제` 버튼만 보이고 수락이 안 되는 경우가 있습니다** (2026-10-28 겪음).
>
> **증상**: `초대` 탭에 앱이 보이는데 `수락` 버튼이 없고 `삭제`만 있다.
> 앱에서도, 브라우저(`threads.com`)에서도, PC에서도 똑같다.
> `활성` 탭은 "승인된 활성 앱 또는 웹사이트가 없습니다" 로 비어 있다.
>
> **해결**: **양쪽을 다 지우고 다시 초대**한다. 한쪽만 지우면 또 꼬인다.
> 1. 스레드 `초대` 탭에서 `삭제`
> 2. 개발자 콘솔 `앱 역할 → 역할` 에서 "대기 중" 인 계정도 **제거**
> 3. `사람 추가 → Threads 테스터` 로 다시 초대
> 4. `threads.com` 을 **탭을 닫았다 새로 열어서** 확인 → 이번엔 `수락` 이 보인다
>
> **수락 여부 판단 기준** (버튼 모양으로 판단하지 말 것):
>
> | 탭 | 뜻 |
> |---|---|
> | `초대(Invites)` 에 앱이 있음 | **아직 수락 안 됨** |
> | `활성(Active)` 에 앱이 있음 | **수락 완료** |

> ⚠️ **여기서 가장 많이 틀립니다.** 초대를 수락할 때 반드시 **`@scribble1013` 으로
> 로그인된 상태**여야 합니다. 핫딜 계정으로 로그인돼 있으면 엉뚱한 계정이 수락됩니다.
> 스레드 앱에서 계정을 먼저 바꾸고 들어가세요.

## 5. 토큰 받아서 GitHub에 넣기

1. **사용 사례 → Threads API 액세스 → 설정** 화면 **아래쪽**의
   **사용자 토큰 생성기(User Token Generator)** 에서 `scribble1013` 옆 **액세스 토큰 생성**을 누릅니다.
2. 로그인하고 권한을 허용하면 긴 글자(토큰)가 나옵니다. 복사합니다.
   - **이 토큰은 비밀번호와 같습니다. 채팅창이나 이슈에 붙여넣지 마세요.**
3. https://github.com/choiyh040-bit/sale/settings/secrets/actions 에서 **New repository secret**
   - Name: `THREADS_ACCESS_TOKEN`
   - Secret: 복사한 토큰
   - **Add secret**

> 저장소를 꼭 확인하세요. **`sale`** 입니다. `link` 에 넣으면 핫딜 토큰을 덮어씁니다.

## 토큰 유효 기간 — 60일

토큰은 보통 **60일** 동안 유효합니다. 만료되면 게시가 실패하고 이슈에 댓글이 달립니다.
그때 **5단계만 다시** 하면 됩니다 (앱·권한·테스터는 그대로).

> 핫딜 토큰도 비슷한 시기에 만료됩니다. 두 저장소의 Secret을 **같이 갱신**하게 되니
> 한쪽만 바꾸고 끝내지 않도록 주의하세요.
